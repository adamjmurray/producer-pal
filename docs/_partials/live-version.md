- [Ableton Live 12.3+](https://www.ableton.com/live/) with
  [Max for Live](https://www.ableton.com/live/max-for-live/). Live 12.4 or later
  is recommended. On Live 12.3 these don't work:
  - the [Library](/features/tools#ppal-library) tool (searching your library and
    listing plug-ins)
  - writing clip automation (reading and clearing it still work)
  - loading a sample into Simpler
  - opening a plug-in's editor window

  Use the version of Max bundled with Live, or make sure your standalone Max is
  up to date.
