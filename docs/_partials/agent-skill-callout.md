The steps below register Producer Pal's tools natively over MCP. The portable
[Agent Skill](/guide/skills) is the other way: it drives the
[REST API](/guide/rest-api) instead, so the agent picks its own
[notation](/features/midi-notation) and toolset per request without moving your
Chat UI or other MCP clients off theirs. Both reach the same tools — pick either
one, or install both.
