# Desktop Apps

Already pay for Claude, ChatGPT, Gemini or Mistral? Add Producer Pal to its
desktop app at no extra cost.

## Claude Desktop

Anthropic's desktop app. Producer Pal installs as an extension.

- **Difficulty:** Easy — download, install, done
- **Cost:** Subscription recommended
- **Best for:** Claude users

[Get started with Claude Desktop →](./claude-desktop)

## ChatGPT App

OpenAI's desktop app, with Codex built in (formerly the Codex app). Easy setup
with an OpenAI account.

- **Difficulty:** Easy
- **Cost:** A paid plan (ChatGPT Plus, Pro, Business, or Enterprise) is
  recommended
- **Best for:** OpenAI users on macOS or Windows

[Get started with the ChatGPT App →](./chatgpt-app)

## Google Antigravity

Google's agent app for Gemini models. Adding Producer Pal means editing a JSON
config file — one extra step, but everything else is the same.

- **Difficulty:** Easy — one config file to edit
- **Cost:** a Google AI subscription is recommended; without one you hit limits
  quickly
- **Best for:** Gemini users who want a desktop app instead of the CLI

[Get started with Google Antigravity →](./antigravity)

## Mistral Vibe

Mistral's desktop app (formerly Le Chat). Adding Producer Pal means editing a
config file, and it works in the app's Code tab only.

- **Difficulty:** Easy — one config file to edit
- **Cost:** A Mistral account (free or paid)
- **Best for:** Mistral users on macOS or Windows

[Get started with Mistral Vibe →](./mistral-vibe)

## Want to Run the AI Offline?

[Bionic / LM Studio](./bionic) is a desktop app that runs the AI on your own
computer. See [Running Locally](./choose-local).
