# Using Claude with Producer Pal

Anthropic's Claude models work great with Producer Pal. A Claude subscription
(Pro, $20/month or higher) is recommended.

## Options

| Option                                   | Best For          | Trade-offs                                                                 |
| ---------------------------------------- | ----------------- | -------------------------------------------------------------------------- |
| [Claude Desktop](./claude-desktop)       | Most users        | Easiest setup, best experience. Desktop app required.                      |
| [Claude Code](./claude-code)             | Developers        | Terminal-based, great for coding workflows.                                |
| [Built-in Chat UI](./api-keys#anthropic) | Direct API access | Requires API key, pay-per-use pricing.                                     |
| [claude.ai](./claude-web)                | Browser only      | Not recommended: needs a public [web tunnel](./remote-access#web-tunnels). |

Claude Code can also use the portable [Agent Skill](/guide/skills) instead of
MCP.

## Recommendation

**Claude Desktop** is the easiest and most reliable option.

## Model Notes

- The latest Claude Sonnet or Opus is recommended for complex musical tasks
- Haiku works for simple operations but may struggle with anything complicated
