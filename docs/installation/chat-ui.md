# Built-in Chat UI

Producer Pal includes a [built-in chat window](/guide/chat-ui) that runs in your
browser. It needs an AI to talk to. Pick one:

- **[Local AI](./local-ai)** — runs on your own computer. Free, private and
  offline, but needs a powerful computer.
- **[AI Routers](./ai-routers)** (recommended) — one account, models from every
  big AI company.
- **[API Keys](./api-keys)** — straight from Google, OpenAI, Anthropic or
  Mistral.
