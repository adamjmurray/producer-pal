# Advanced

Setups for less common configurations and remote access.

## [Other MCP LLMs](./other-mcp)

Already have an MCP-compatible app? Connect it directly with
[`npx producer-pal`](https://www.npmjs.com/package/producer-pal) — no dedicated
guide needed for your specific client.

## [Web Tunnels](./web-tunnels)

Web apps can't reach `localhost`. To use Producer Pal from a browser-based AI
(claude.ai, ChatGPT, Le Chat), expose your local server through a tunnel like
Cloudflare or Pinggy.
