# Using OpenAI with Producer Pal

OpenAI's models work with Producer Pal through several options. A ChatGPT Plus
subscription or API credits is recommended for regular use.

## Options

| Option                                | Best For          | Trade-offs                                                                 |
| ------------------------------------- | ----------------- | -------------------------------------------------------------------------- |
| [ChatGPT App](./chatgpt-app)          | Most users        | Easy setup.                                                                |
| [Codex CLI](./codex-cli)              | Developers        | Terminal-based, good for scripting.                                        |
| [Built-in Chat UI](./api-keys#openai) | Direct API access | Requires API key, pay-per-use pricing.                                     |
| [ChatGPT Web](./chatgpt-web)          | Browser only      | Not recommended: needs a public [web tunnel](./remote-access#web-tunnels). |

Codex CLI can also use the portable [Agent Skill](/guide/skills) instead of MCP.

## Recommendation

**[ChatGPT App](./chatgpt-app)** (formerly the Codex app) for the easiest setup.
**[Built-in Chat UI](./api-keys#openai)** if you prefer pay-as-you-go API
pricing.

## Model Notes

- GPT-6.1 Sol recommended by default
- Also available: GPT-6 Luna, GPT-6 Astra
